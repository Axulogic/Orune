# Security Policy

Orune is not yet released as an open-source project. This repository may not represent a supported public release.

## Supported versions

No public release is currently supported. Once releases are published, supported versions and security-update guidance will be documented here.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository instead of opening a public issue. If private reporting is unavailable, contact the maintainer through the GitHub profile.

Include a concise description, affected version or commit, reproduction steps, and impact. Do not include API keys, tokens, passwords, or personal data in a report.

## Scope

Please report security issues involving Orune itself, including credential handling, local data protection, IPC boundaries, release artifacts, and provider integrations. Provider outages, rate limits, third-party service vulnerabilities, and ordinary feature requests should be reported through their appropriate channels instead.
